# Azmeer Pirani — Portfolio

Static portfolio website for GitHub Pages.

## Pages

- `index.html` — home page
- `work.html` — project archive
- `contact.html` — contact page
- `privacy.html` and `terms.html` — policy pages
- `video-board.html` — standalone video work page
- `CNAME` — custom domain for GitHub Pages

Keep these pages in the repository root so their public URLs and relative asset links continue to work.

## Assets

- `assets/css/` — page and component stylesheets
- `assets/js/` — site interactions and page behavior
- `assets/img/` — interface and decorative images
- `assets/media/profile/` — profile photos
- `assets/media/hackathons/` — event photos and event design files
- `assets/media/github/` — project images grouped by project
- `assets/media/videos/` — video samples grouped by format

## Preview locally

Open `index.html` in a browser, or serve this folder with any local static web server. The site has no build step.
